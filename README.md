# 回到三國：軍火商求生記

3D 第一人稱生存遊戲。你是一名現代軍火商，穿越到東漢末年，身上只有一把**備彈無限的手槍**，以及**熱兵器與彈藥製作**的知識。

純前端（three.js，已內含於 `vendor/`），無需建置、無外部素材——模型、音效、配樂皆由程式即時生成。

## 執行

ES Module 需透過 HTTP 載入，請在專案根目錄啟動任一靜態伺服器：

```bash
npx http-server -p 8080     # 或 python3 -m http.server 8080
```

然後開啟 <http://localhost:8080>。也可直接啟用 GitHub Pages（Settings → Pages → 選擇分支根目錄）。

## 內容

- **開場動畫**：新遊戲會先播約 50 秒的開場（可點擊或按任意鍵跳過，暫停選單可重看）：2026 年港口倉庫的軍火交易、買家帶來的「太平道青銅羅盤」、槍戰與爆炸、羅盤撕開時空裂縫、裂縫中獲得無限子彈與火器知識，最後墜落在中平元年（西元 184 年）的荒野。

- **世界**：1 km² 程序生成地形——河流、森林、竹林、日夜循環；劉備軍營、黃巾營寨、聯軍大營、汜水關、虎牢關、郿塢，以及隨主線出現的友軍前哨營。
- **求生**：生命、飽食、水分、體力；採集野果草藥、狩獵野鹿、河邊或水井取水、夜間狼群與賊兵夜襲、營地臥榻過夜存檔。
- **熱兵器製作**：製作頁分成彈藥、火器、投擲・爆破、求生・醫療、材料加工五類，分類標籤上會顯示目前能做幾樣。硝石＋硫磺＋木炭 → 黑火藥 → 震天雷（手榴彈）、霰彈槍、步槍（附瞄準鏡）與彈藥。軍火可賣給糜竺換五銖錢。
- **三國兵器**：環首刀、長矛、長弓、方天畫戟（擊敗呂布取得）；名將各持青龍偃月刀、丈八蛇矛、雙股劍、九節杖等。
- **馬匹**：軍營戰馬、野馬可馴服騎乘，馬上可射擊劈砍；擊敗呂布後可得赤兔馬。
- **招兵買馬**：向劉備（槍兵、刀兵）、曹操（弓弩手、騎兵）、孫堅（刀盾兵）用錢或資源招募兵卒。隊伍名額隨主線增加（3 → 8），兵卒佔 1、名將佔 2；兵卒陣亡後需重新招募。按 `V`／⚑ 切換跟隨、原地堅守、自由攻擊。
- **名將招攬**：擊敗張角後可招攬關羽、張飛；擊敗華雄後可招攬趙雲、曹操、孫堅；擊敗呂布後可招攬劉備。解鎖後付一次錢或資源（300～600 錢，或乾糧＋鐵礦＋黑火藥），之後可隨時同行或回營。名將不會陣亡，倒下會回營休養。糜竺經營商攤。
- **侍從**：與劉備談完後獲贈小廝阿福；不會打仗也不會受傷，會定時去附近採集物資，可交談領取物資、詢問附近資源方位、下一步提示、目前能製作什麼，或指定專門採集、原地留守。另可向三位主公僱用樵夫、礦工、藥童（最多 3 位）。
- **敵將決戰**：每位頭目周圍有發光的決戰圈，玩家在圈內才能造成傷害；離開圈子頭目會慢慢回血。第一次踏入決戰圈時播放開戰動畫（可點擊跳過）。
- **主線**：投奔劉備 → 討伐張角 → 斬華雄 → 三英戰呂布 → 誅殺董卓 → 官渡之戰（白馬斬顏良、延津誅文醜）→ 火燒烏巢 → 長坂坡（守橋 75 秒、戰夏侯恩）→ 赤壁之戰（火燒連環船、擊退曹操）。頭目各有技能（落雷、衝鋒、連珠箭、召喚護衛、重傷敗走）。長坂坡起曹操與你為敵。
- **武將單挑**：進入決戰圈時選「單挑」或「群戰」。單挑時隊友退到圈外、敵兵旁觀，勝利賞金加倍並必定奪得專屬兵器（九節杖、大環刀、方天畫戟、七星寶刀、河北寶甲、鐵胎弓、青釭劍、倚天劍）；群戰只有 25% 機率掉落。
- **軍火外流**：西邊黑市的掮客以兩倍價格收購軍火，也收「火器圖紙」。賣得越多，敵軍中的火銃兵越多（最高 35%），劉備的聲望下降，並決定三種結局之一。

- **軍火訂單與聲望**：劉備、糜竺（擊敗張角後還有曹操、孫堅）每天會下一張訂單，例如「三天內交 20 發步槍彈」。準時交貨得錢與聲望，逾期扣聲望；同時最多 3 張。聲望 15 點「信賴」招兵 9 折，35 點「摯友」8 折並可招募精銳（白毦兵、虎豹騎、丹陽兵）；糜竺的聲望讓商攤打折。
- **天氣**：晴、陰、雨、霧隨機變化。下雨時待在營地外，自製黑火藥彈藥會受潮啞火、震天雷可能不炸，背包裡的黑火藥也會變成受潮火藥（可在營火旁烘乾）；手槍是現代密封子彈，不受影響。油布包可大幅減緩受潮。起霧和下雨會縮短敵人視野。
- **軍火工坊**：與劉備談過後，可在劉備營外西北的空地蓋工坊（附營火、可躲雨）。升級三種建築（各 3 級）：火藥坊每輪自動燒炭、配黑火藥、烘乾受潮火藥；鐵匠爐每輪自動造指定彈藥（霰彈、步槍彈、箭矢、震天雷、燃燒彈、地雷）；倉庫加大容量（40 → 400）。每輪 60 秒，原料存進工坊倉庫就會自動生產。侍從可派駐工坊，採到的東西直接進倉庫，每人讓每輪多做一批。
- **武器改良**：在工坊替手槍、霰彈槍、步槍改良彈匣、準度、傷害，各 2 級；改良等級上限等於鐵匠爐等級。
- **燃燒彈與地雷**：燃燒彈落地起火，持續灼燒範圍內敵人（雨天燒得短）；地雷埋在地上，敵人踩到就爆炸，最多同時 6 顆。
- **敵軍目標**：敵人會優先攻擊視野內最近的我方兵卒、名將；附近沒有隊友時才衝著玩家來。
- **友軍前哨營**：主線每推進一步，下一個頭目據點前方就會設立前哨營（共 8 座）：營帳、營火、水井、兩名守衛，是安全區（不會有巡邏賊兵、狼群、夜襲），可躲雨、就寢。抵達即設為重生點；令旗台可存檔、時空傳送。陣亡的守衛黎明時補足。
- **呂布陣亡與阿凱**：擊敗呂布後播放陣亡動畫，接著傳送門暴走，掉出另一位穿越者——2031 年研究青銅羅盤碎片的研究員林凱（阿凱）。到傳送門找他交談，他就會跟著你行動。阿凱不會攻擊、也不會被攻擊，戰鬥時變成半透明；可以叫他原地等候。
- **羈絆**：同行、聊天（每天一次）、送食物、一起完成主線都會提升羈絆。Lv1 戰場分析（顯示敵人血條、偵測範圍變大）→ Lv2 現代急救（回血 2.5 倍）→ Lv3 防潮塗層（受潮、啞火減半）→ Lv4 緊急救援（每天一次倒下時被救回）→ Lv5 科技改良（製作材料 8 折、工坊有機會不耗原料、送你現代零件，並解鎖「凱式特製步槍」：子彈完全無限、不用換彈匣、不怕受潮，精準；單發威力比手槍略強（44），連續射擊約 6 秒會過熱，要冷卻 2～3 秒才能再開火，點放就不容易過熱）。
- **傳送門儀器**：擊敗董卓後，傳送門旁的儀器亮起，隨主線解鎖功能：時空傳送（董卓；儀器、驛站、前哨營之間瞬移，隊友和馬一起走，附近有敵人時不能用）→ 地脈探測（白馬延津；大地圖顯示礦點、草藥與遠處火銃兵）→ 時空郵包（烏巢；每天在傳送門旁送來補給箱）→ 借東風（長坂坡；每天一次轉晴並颳起 5 分鐘東南風，燃燒彈更猛）→ 歸途之門（赤壁；可選擇回到 2026 年或留在三國，回家的結局依軍火外流程度與阿凱的羈絆而不同）。
- **官職與戰功**：殺敵、斬將（+30）、單挑（+20）、完成一回（+20）、守營、交貨都會累積戰功。達到門檻就由劉備下令冊封：白身 → 鄉勇隊正 → 軍司馬 → 別部司馬 → 騎都尉 → 中郎將 → 偏將軍 → 蕩寇將軍。冊封時展開直書的令、蓋上官印，附近弟兄抱拳道賀。官職帶來每天清晨發放的日俸、部分官職增加隊伍名額，友軍對你的稱呼也會從「先生」改成「司馬」「都尉」「將軍」。左下狀態欄會顯示官職與距離下一階的戰功。
- **頭目終結演出**：擊敗頭目的瞬間進入慢動作，畫面打出毛筆大字「斬　某某」（曹操是「退」）並蓋上朱印，響起鑼鼓；附近敵兵潰散逃跑，弟兄們舉兵器歡呼。
- **章節卷軸與戰功簿**：每一回開始時展開一張卷軸，寫著回目、年份、地點與一句詩文；每回結束時結算戰功簿（用時、擊殺、是否單挑、倒下次數、陣亡兵卒、本回戰功），蓋上甲上／甲等／乙等／丙等的評定印。這些儀式會排隊播放，等附近沒在打仗時才出現。
- **火光與夜晚**：篝火周圍有暖光與光暈，夜裡照亮一片；小兵天黑後會陸續點起火把舉在手上，天亮再熄掉（弓手、火銃兵雙手要拿武器，不拿火把）。光源由一組固定數量的點光源分配給離玩家最近的火源，手機也看得到。
- **戰術手電筒**：按 `L`（手機：右上的手電筒鍵）開關，照亮前方。代價是夜裡開著燈，敵人在更遠處就會發現你。
- **名將絕技**：同行的名將各有一招，按 `Q`（手機：★ 絕技鍵）下令發動，各自冷卻。關羽「拖刀斬」衝入敵陣橫掃一圈；張飛「當陽怒吼」震懾周圍敵人 4 秒；趙雲「七進七出」連續突刺 7 次；劉備「仁德激勵」治療友軍與你並提升友軍攻擊；曹操「虎豹突騎」召來三名虎豹騎助戰 25 秒；孫堅「猛虎破陣」躍入敵陣重擊並震倒敵人。隊伍列表會顯示絕技是否就緒，與名將交談可以詢問絕技內容。
- **守營戰**：投奔劉備後，可在任何營區的令旗台發起（每天一場）。敵軍分 3～5 波來攻軍旗，後面幾波會兩面夾擊，最後一波有「敵軍先鋒」帶隊。開戰前有 20 秒可以埋地雷、佈置隊伍；敵兵會和擋路的守軍廝殺，沒人擋就去砍軍旗，其中標著「破旗手」的會不理守軍、直奔軍旗。守住可得錢、補給與劉備聲望，並升到下一級（共 5 級，越高敵人越多、獎賞越好）；軍旗被毀、你倒下或離營太遠就算失敗。
- **難度**：開始新遊戲時可選簡單／普通／困難（影響敵我傷害、飽食與水分消耗、倒下時損失的錢），遊戲中也能在設定裡更改。
- **新手引導**：新遊戲開頭會一步一步提示移動、開箱、射擊、採集、製作、進食喝水、前往劉備軍營，完成一步才進下一步；可以跳過，也能從暫停選單重看。
- **NPC 動作與台詞**：士卒、名將、頭目、侍從、阿凱頭頂會冒出對話泡泡。閒置時伸懶腰、張望、抓頭、磨兵器、打哈欠、坐下休息，名將會撫髯、耍兵器；友軍看到你會抱拳打招呼，同袍之間會一問一答閒聊（各陣營、夜晚、雨天台詞不同）。發現敵人時舉兵器吶喊；對戰時擺出架勢、等待出手時繞著對手移步，揮擊時扭腰前衝，被打中會後仰，重傷時佝僂。另有出招、受傷、重傷求饒、擊倒對手後舉兵器歡呼、陣亡遺言等台詞；頭目的台詞也會出現在訊息列。附近開打時侍從會抱頭蹲下。
- **自訂按鍵配置（手機）**：設定 →「按鍵配置」可以拖曳每一顆按鍵（開火、瞄準、跳躍、換彈、各快捷鍵、背包、暫停、兵器列、彈藥資訊、互動提示、小地圖）到任意位置，用雙指捏合或拉桿調整大小（50%～200%）。移動搖桿可以選擇「浮動」（左側任意處按下）或「固定」位置。橫向與直向各存一份，可單鍵恢復或全部恢復預設。
- **設定**：開始畫面與暫停選單都能進入，可調滑鼠／觸控靈敏度、畫質（自動／低／中／高）、音效與配樂音量、手機按鍵大小與按鍵配置，設定會記住。

### 存檔槽與雲端存檔

- **3 個存檔槽**：開始新遊戲時選槽（已有存檔的槽要按兩次確認才會覆蓋）；標題頁的「繼續遊戲」讀最近一次的存檔，「存檔槽」可挑槽讀取或刪除。每個槽顯示日數、章節、官職、遊玩時間與存檔時間。舊版的單一存檔會自動搬到存檔 1。
- **暫停選單**：「立即存檔」存到目前的槽，「存檔槽・另存」可存到別的槽（之後的自動存檔改寫到那裡），「返回標題頁」會先存檔、等雲端上傳完再回到標題畫面。切到背景、令旗台、就寢、過章節也都會自動存檔。
- **雲端存檔**：在 claude.ai 的遊戲頁面登入時，存檔會自動同步到玩家自己的私人空間（平台的 `db`，路徑 `data/users/<玩家id>/slot1～3`，連頁面擁有者也看不到），換裝置也能接著玩。同一個槽以最後存檔時間較新的為準，刪除也會同步。分享給別人時要給「貢獻者」以上的權限才能寫入雲端；在其他環境（本機、GitHub Pages）沒有雲端，會安靜地只存本機。設定（靈敏度、按鍵配置）只存在各自的裝置。
