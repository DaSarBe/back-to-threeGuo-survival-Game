# 回到三國：軍火商求生記

3D 第一人稱生存遊戲。你是一名現代軍火商，穿越到東漢末年，身上只有一把**備彈無限的手槍**，以及**熱兵器與彈藥製作**的知識。

純前端（three.js，已內含於 `vendor/`），無需建置、無外部素材——模型、音效、配樂皆由程式即時生成。

## 執行

ES Module 需透過 HTTP 載入，請在專案根目錄啟動任一靜態伺服器：

```bash
npx http-server -p 8080     # 或 python3 -m http.server 8080
```

然後開啟 <http://localhost:8080>。也可直接啟用 GitHub Pages（Settings → Pages → 選擇分支根目錄）。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `W A S D` / `Shift` / `空白` | 移動 / 奔跑 / 跳躍 |
| 滑鼠左鍵 / 右鍵 / `R` | 攻擊 / 瞄準 / 換彈 |
| `1–7`、滾輪 | 切換兵器 |
| `E` | 互動、採集、交談、上下馬 |
| `G` / `F` / `Z` / `H` | 投擲震天雷 / 進食 / 喝水 / 金瘡藥 |
| `X` | 吹哨喚馬 |
| `Tab` | 製作 / 背包 / 地圖 |
| `M` / `Esc` | 配樂開關 / 暫停 |

### 手機／平板

觸控裝置會自動切換成手機介面（建議橫向握持，直向也可遊玩）：

- 左半螢幕拖曳移動（推到底奔跑），右半螢幕拖曳轉視角；按住「開火」可邊射擊邊瞄準
- 點下方兵器列切換兵器；🍖💧💊💣🐴 為快捷道具（附數量）
- 出現金框提示時點它即可互動；點左上任務可展開說明
- 自動嘗試全螢幕與橫向鎖定、避開瀏海安全區、掉幀時自動降低解析度

## 內容

- **世界**：1 km² 程序生成地形——河流、森林、竹林、日夜循環；劉備軍營、黃巾營寨、聯軍大營、汜水關、虎牢關、郿塢。
- **求生**：生命、飽食、水分、體力；採集野果草藥、狩獵野鹿、河邊或水井取水、夜間狼群與賊兵夜襲、營地臥榻過夜存檔。
- **熱兵器製作**：硝石＋硫磺＋木炭 → 黑火藥 → 震天雷（手榴彈）、霰彈槍、步槍（附瞄準鏡）與彈藥。軍火可賣給糜竺換五銖錢。
- **三國兵器**：環首刀、長矛、長弓、方天畫戟（擊敗呂布取得）；名將各持青龍偃月刀、丈八蛇矛、雙股劍、九節杖等。
- **馬匹**：軍營戰馬、野馬可馴服騎乘，馬上可射擊劈砍；擊敗呂布後可得赤兔馬。
- **名將**：劉備、關羽、張飛、趙雲、曹操、孫堅可交談並邀請同行（最多三位）；糜竺經營商攤。
- **主線**：投奔劉備 → 討伐張角 → 斬華雄 → 三英戰呂布 → 誅殺董卓。頭目各有技能（落雷、衝鋒、召喚護衛）。

進度自動存於瀏覽器 localStorage。

## 結構

```

js/world.js     地形、天空、據點建築、資源點、碰撞與尋路
js/entities.js  士兵／名將 AI、動物、投射物、特效、掉落物

js/models.js    人物、馬匹、兵器的程序化模型
js/ui.js  js/quests.js  js/data.js  js/audio.js  js/util.js  js/state.js
```
